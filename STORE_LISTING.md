# Chrome Web Store Listing

## Name
Copy URL (Cmd+Shift+C)

## Summary (132 chars max)
Copy the current tab's URL to clipboard with Cmd+Shift+C - the same shortcut Arc browser uses.

## Description
A lightweight extension that adds a keyboard shortcut to copy the current tab's URL to your clipboard.

**Why this extension?**
If you're used to Arc browser's Cmd+Shift+C shortcut for copying URLs, this extension brings that same muscle memory to Chrome.

**Features:**
- Cmd+Shift+C on Mac (Ctrl+Shift+C on Windows/Linux)
- Copies just the URL - clean and simple
- No popup, no toolbar icon clutter
- Minimal permissions - only accesses the active tab when you use the shortcut

**Note:** This overrides Chrome's default "Inspect Element" shortcut. You can still access DevTools via right-click → Inspect or Cmd+Option+I.

This extension:
- Does NOT collect any data
- Does NOT track browsing history
- Does NOT communicate with external servers
- Only reads the URL of the active tab when you press the shortcut
